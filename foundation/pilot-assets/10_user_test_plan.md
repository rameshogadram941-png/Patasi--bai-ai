10-User Usability Test Plan

Objective: Validate WhatsApp onboarding, listing generator, and payment flow with 10 users within Mohra Kalan.

Steps:
1) Recruit 10 representative users (women sellers / SHG members)
2) Baseline: capture name, phone, product, monthly income
3) Run Session 1: assist each user to create 1 listing via WhatsApp flow
4) Verify listing quality: title, price, description, photo
5) Send a test payment link (Razorpay test mode) and complete payment with trainer
6) Collect user feedback survey (5 quick questions) and record time-to-complete
7) Document issues and refine scripts

Metrics:
- Time to onboard (minutes)
- % successful listings
- % successful test payments
- User satisfaction (1-5)

Deliverable: short one-page findings report and recommended fixes
